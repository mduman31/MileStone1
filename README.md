# 🌺 MileStone1 - Personal Portfolio

Welcome to my personal web portfolio website! This project features a clean, responsive layout built with a custom **Lilo & Stitch (Stitch Blue & Angel Pink)** aesthetic, complete with a real-time weather widget tracking local weather data.

## ✨ Features
*   **Stitch & Angel Theme:** A cohesive design using deep outer-space blues, tropical sky accents, and soft pastel pink highlights.
*   **Live Weather Integration:** An active widget pulling live, real-time meteorological data directly from the National Weather Service API.
*   **Responsive Grid Layout:** Built using modern CSS Grid so it looks great on desktop computers, tablets, and smartphones.

## 📍 Widget Configuration
*   **Target Location:** New Castle, DE 19720
*   **Data Feed Source:** National Weather Service (NWS) API

## 🚀 How to Run the Project Locally

If you want to view or test this portfolio on your computer using **VS Code**:

1.  **Clone or Download** this repository to your local computer.
2.  Open the folder inside **VS Code**.
3.  Right-click on `index.html` and choose **Open with Live Server** (or locate the file on your computer, right-click, and open it with your web browser like Chrome or Edge).
4.  Ensure you have an active internet connection so the weather card can reach out and load live Delaware data.
